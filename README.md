# Kaminari

## Features
- Epub/Ebook reader
- Webnovel and Lightnovel importing and offline reading
- English dictionary
- Japanese novel transliteration (with kanji breakdown for language learners)

## planned Features
- Manga/Manwa/Manhua/Webtoon (comics) reader
- Comic importing and opt in offline reading
- Opt in image scanning + language detection for transliterating comics (with kanji breakdown for language learners
